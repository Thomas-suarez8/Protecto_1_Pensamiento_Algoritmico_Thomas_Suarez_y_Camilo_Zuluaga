# Protecto_1_Pensamiento_Algoritmico_Thomas_Suarez_y_Camilo_Zuluaga

Presentacion proyecto, Modulo y Consola de peliculas - Thomas Suarez y Camilo Zuluaga

Descripcion general del proyecto: El programa inicia creando cinco películas con diferentes características, luego entra en un ciclo while que mantiene activa la aplicación hasta que el usuario decida salir. Dentro de ese ciclo se muestra el menú y se ejecuta la opción que el usuario elija.

Prueba 1: Se evidencia que se puedan ver la agenda de peliculas al momento de ejecutar el programa.

Opcion 1 (Consultar pelicula mas larga):  Busca y muestra la película con mayor duración dentro de la agenda.

Opcion 2 (Consultar duracion promedio de las peliculas): Calcula el promedio de duración de todas las películas registradas.

Opcion 3 (Consultar peliculas de estreno): Muestra las películas estrenadas después de un año ingresado por el usuario.

Opcion 4 (Consultar cuantas peliculas tienen clasificacion 18+): Cuenta cuántas películas son solo para mayores de edad.

Opcion 5 (Reagendar pelicula): Permite cambiar el día y la hora de una película de la agenda.

Opcion 6 (Verificar si se puede invitar a alguien): Determina si una persona puede ver una película según su edad y autorización.

Opcion 7 (Buscar pelicula): Busca una película por nombre y muestra toda su información.

Opcion 8 (Salir de la aplicacion): Finaliza la ejecución del programa y cierra la agenda de películas.
